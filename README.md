# Análisis de datos de cadena de supermercados en EE.UU.

## Descripción
Este proyecto simula la solicitud de un **cliente que requiere el análisis de datos de una cadena de supermercados en Estados Unidos**.  
El cliente proporciona una idea general de sus necesidades, pero solicita **extraer el máximo valor posible del conjunto de datos**.  
El objetivo es **obtener información relevante mediante visualizaciones** y aplicar **algoritmos de machine learning** para modelar los datos, generando **hallazgos que permitan aprovechar al máximo la información disponible**.

---

## Dataset
El conjunto de datos corresponde a una cadena de supermercados en Estados Unidos e incluye información sobre **ventas, productos, clientes y tiendas**.  
Estos datos permiten analizar el comportamiento de compra, identificar patrones de consumo y explorar tendencias de negocio.

---

## Metodología
El proyecto se desarrolló siguiendo un flujo estructurado de análisis y modelado de datos:

1. **Análisis exploratorio de datos (EDA):**  
   Identificación de patrones, relaciones entre variables y detección de valores atípicos mediante gráficos y estadísticas descriptivas.

2. **Limpieza y transformación de datos:**  
   Tratamiento de valores nulos, normalización de variables numéricas y conversión de variables categóricas.

3. **Construcción de pipelines:**  
   Implementación de **pipelines automáticos** para la limpieza, transformación y modelado, facilitando la reproducibilidad del flujo de trabajo.

4. **Modelado con machine learning:**  
   Se aplicaron diferentes algoritmos supervisados y no supervisados para generar predicciones, segmentaciones y detección de patrones de comportamiento.

5. **Visualización y comunicación de resultados:**  
   Uso de **Power BI** y **Excel** para presentar hallazgos mediante dashboards y reportes visuales que facilitan la toma de decisiones.

---

## Resultados
El proyecto permitió **automatizar el flujo de trabajo mediante pipelines**, lo que facilita la actualización y ejecución del análisis de manera eficiente.  
Además, se **versionó el proyecto según objetivos**, organizando cada etapa del desarrollo para mantener una estructura clara y escalable.  
La simulación de un **caso real** permitió aplicar buenas prácticas de análisis de datos y gestión de proyectos.

---

## Lecciones aprendidas
- Diseño y aplicación de **pipelines personalizados** para diferentes flujos de trabajo.  
- Estructuración y **versionado de proyectos de datos** de acuerdo con objetivos definidos.  
- Aplicación práctica de **machine learning en un contexto de negocio real**.  
- Importancia de combinar análisis exploratorio con visualización interactiva.
